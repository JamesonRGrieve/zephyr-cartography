# Installation

## Requirements

- Foundry VTT **version 14**.
- Any game system.
- Optional: an asset-pack module for stamps and textures (see [Asset Packs](?path=/docs/guide-asset-packs--docs)).
- Optional: [Item Piles](https://foundryvtt.com/packages/item-piles), so container stamps become lootable containers.

## Install

1. In Foundry's setup screen, open **Add-on Modules** and click **Install Module**.
2. Search for **Zephyr's Cartography**, or paste this manifest URL into the **Manifest URL** field:

   ```
   https://github.com/JamesonRGrieve/zephyr-cartography/releases/latest/download/module.json
   ```

3. Click **Install**.
4. Launch your world, open **Game Settings → Manage Modules**, tick **Zephyr's Cartography**, and save.

### Testing the latest build

A rolling build of the development branch is published on every change. It is a prerelease and may be unstable. To try it, install from this manifest URL instead:

```
https://github.com/JamesonRGrieve/zephyr-cartography/releases/download/nightly/module.json
```

## Updating

Foundry checks installed modules for updates from the setup screen: **Add-on Modules → Check for Updates**. A module installed from the first manifest URL follows each new release.

## First steps

1. Open a scene and pick the **Cartography** group (the map icon) in the scene controls on the left.
2. Choose **Paint terrain** and click or drag on the canvas to paint ground.
3. Choose **Road**, click a few points, and right-click to finish the road.
4. Open **Walls** in Foundry's controls, choose **Room**, click the corners of a room, and right-click to finish it. It gets walls and a light.
5. Use **Undo** and **Redo** in the Cartography group to step back and forward.
